# Agent 文档索引

本文供 Agent 按任务选读，并供 `pnpm verify:docs` 校验登记与日期。贡献者阅读入口为 [docs/index.md](../docs/index.md)；通用规则仍以根 [AGENTS.md](../AGENTS.md) 和目标路径的目录规则为准，不要求加载全部文档。

登记文档及统一存放于 `docs/plans/` 的任务与计划；计划不按进行中或已完成分栏，状态在正文与表格中标注。代码与测试证明实现现状。纯路径迁移不推进复核日期，专题计划的文件名前缀、唯一维护日期与下表日期必须一致；持续维护的任务清单使用固定文件名 `todo.md`。文档维护方法见 [docs-maintenance](skills/docs-maintenance/SKILL.md)。
