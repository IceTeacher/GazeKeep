# 真实完整旅程

验证 Android 页面、相机、引擎与后端连接后的行为，包括实际熄屏与恢复。按[实机矩阵](../../../docs/development/testing.md#实机完整矩阵)选择本次场景，并读取目标后端架构；发布验收覆盖完整矩阵，局部修复聚焦受影响路径。fake 与主机测试不证明硬件兼容。

## 环境与授权

- 核对设备、代码/APK、ROM/Android、后端/框架版本、权限、系统超时、作用域和配置；按能力选设备，不指定优先机型。
- 安装、重启与系统操作核对本次授权，已有授权不重复询问；高风险错误钩点等场景须有恢复方法。缺设备、权限或框架明确记未执行，不套用旧 APK 结果。

## 关键证据

- UI 与后端成功路径连接真实组件；不 Extend 不能替代 Hold 释放与实际熄屏。
- 涉及 Shizuku 恢复时验证原系统超时写回；涉及 LSPosed 时核对实际入口、签名、旧 seq 与作用域行为。
- 阈值变更使用[分类计数场景](../../../docs/development/testing.md#分类与页面场景)，只留计数与耗时，不保存人脸图像或特征。

## 清理与记录

恢复临时配置与服务状态；失败报告残留及恢复方法，不擅自清空应用数据。按[记录要求](../../../docs/development/testing.md#记录与验收状态)交付本次结果、缺失条件和版本证据；发布说明引用对应版本实测范围及实际命中候选。

不保存人脸、概率/角度、序列号或原始 dumpsys；样本只保留所需 power 字段并脱敏。ADB 连接不改变 APK 禁止 INTERNET 的承诺。apps/web 尚无网站或 E2E 入口。
