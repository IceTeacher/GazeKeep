# 产品定义

GazeKeep（注视保亮）为缺少系统级「注视不熄屏」能力的 Android 手机提供短时端上注视检测。兼容性取决于 Android、ROM、相机与后端能力，必须按目标环境验证。

## 目标与成功标准

面向阅读、浏览长文、菜谱和操作说明等无持续触摸场景。临近系统降亮或熄屏时取前摄 1～3 帧，只有可信注视才重置一次超时；离开、未知和链路失败均放行系统。

阅读超过系统超时仍保持亮屏；转头后本轮或下一轮正常熄屏；系统相机与扫码优先使用摄像头。以上是产品目标，具体通过范围以[测试记录](testing.md)为准。

## v1 边界

包含总开关、后端自动/锁定选择、提前量、灵敏度、应用白名单、单次保亮上限、隐私页与自检。默认关闭、白名单开启且为空；不默认对所有应用生效。

不做人脸注册、身份识别、视线落点、眼控滚动、云同步、持续录像或 iOS。ML Kit bundled 是现有实现，MediaPipe 与暗光增强属于后续方向，不作为现有能力。

目标需要门控休眠的场景包括锁屏/息屏、通话、视频自身保亮、口袋/朝下和相机占用。当前传感器、应用来源等门控未全部落地，见[任务清单](../tasks/todo.md)。

## 使用体验

采用 HyperOS 设置层级与 miuix 交互：主页只展示必要状态，检测、范围、保护、隐私与后端详情分页面。正视结果不弹提示；异常才通知并限频。

用户结果统一为「注视了屏幕 / 未注视屏幕 / 这次没看清」。内部枚举与产品语言分开；Unknown 的解释不同于 Away，二者都不保亮。
