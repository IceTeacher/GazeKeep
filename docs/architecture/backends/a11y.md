# 无障碍后端

GazeA11yService、A11yKeepAwakeBackend 和 A11ySignals 位于 backend:a11y，运行在 App 主进程。事件只消费类型、包名、时间；不取 source、文本或窗口内容。

## 信号与亮屏窗口

canRetrieveWindowContent=false。TYPE_TOUCH_INTERACTION_START 与 overlay ACTION_OUTSIDE 都可产生真实用户活动。信号主线程同步投递，先向 reducer 提交 UserActivity，再让 IdleClockOracle 发布 deadline，避免先 Armed 后取消造成静默停止。

可关闭订阅归属于会话；关闭旧订阅不能清掉新订阅。服务解绑立即摘 overlay，release/detach 不能残留常亮锁。

小米 12 Pro 实测 Pulse 300 ms 未重置完整周期，当前默认 Hold；Pulse 保留供其他 ROM 验证，不能宣称首选已普遍有效。见 [ADR 0003](../../adr/0003-accessibility-hold-mode.md)。窗口是无障碍窗口，不申请 SYSTEM_ALERT_WINDOW。

## 超时与限制

IdleClockOracle 根据系统超时和真实用户活动估算，读取 framework 最大降亮时长/比例，以 min(maxDuration, timeout×ratio) 估算 dim；未知配置回退 off−lead。它不等同于系统运行时有效超时，视频或其他策略覆盖须实测。

用户离开、Unknown 或中止必须释放 Hold，让系统按自身语义熄屏。当前 MaxHold/GateSkip 缺 Release 的差距必须修复并验收，不得用 reducer 不 Extend 测试宣称 Hold 到点已熄。

验证入口：A11ySignalsTest 与[无障碍实机记录](../../testing/m1-accessibility.md)。触摸、关闭服务、相机占用、门控跳过和最长保亮须有新版本证据。
