# UI 与自检

shared 的 commonMain 使用 miuix，只依赖 core 和平台契约。App 组装主题、状态与导航；页面处理交互，Android 实现权限、文件与硬件能力。

## 页面定位

| 页面            | 职责                                                      |
| --------------- | --------------------------------------------------------- |
| Home            | 总开关、运行状态、最近检测、系统环境摘要和隐私入口        |
| Settings        | 检测参数、保护上限、白名单、日志和工具入口                |
| Backend         | 后端选择、就绪状态与设置引导                              |
| Apps            | 启动器应用搜索、白名单勾选                                |
| Logs            | 搜索、级别筛选、卡片/原始视图、分享、导出、清空与滚动定位 |
| Privacy         | 三条隐私文案，以及默认熄屏、相机避让、暗光暂停说明        |
| SelfTest        | 正视与转头两步验证；唯一允许相机预览的页面                |
| About / Notices | 项目信息、核心依赖与完整第三方许可                        |

Home 和 Settings 为底栏标签；二级页面隐藏底栏，返回恢复上一页，旋转保留导航与搜索状态。二级转场使用 Compose 的 FastOutSlowInEasing，时长 450 ms；一级标签保持 220 ms 淡入淡出，不维护自制阻尼公式。

主页最近检测不依赖详细日志开关，服务重配时保留。设置数值范围及持久化见[运行架构](android-runtime.md)，不在 UI 文档重复维护。

实验性「隐藏相机隐私指示器」开关仅在 LSPosed 就绪且选择自动或 LSPosed 时可用。开启须二次确认；可用条件失效或外部状态已经开启时关闭弹窗，确认时再次检查。关闭无需确认，禁用状态同时以文字和 Badge 表达。

## 平台契约与资源

GazeKeepController 发布配置、运行、自检、应用列表和日志状态，并处理配置写入、启停、自检及列表/日志操作。保存与启用失败通过 UiNotice 表达，UI 不直接操作配置文件、服务或 Binder。

PlatformActions 负责授权、系统设置、外部链接、日志分享/SAF 导出、返回、预览、图标与日志时间格式化。日志统一使用 Android 标准日期 API，保持 UTC+8 和 MM-dd HH:mm:ss；卡片、原始视图、分享与导出一致。不申请网络或存储权限。

应用列表只查询启动器可见应用，不申请 QUERY_ALL_PACKAGES；区分未加载、加载中、已加载和失败，已加载的空结果不继续显示加载提示，失败可重试。图标预读取可取消。

许可搜索按依赖条目筛选，保留完整前言与所需许可附录；直接命中许可时展示完整声明，空查询保留原文，不能按空行截断许可。

## 自检与启用

步骤为 Looking→Away→Complete；Unknown 不推进。完成时间存入 ConfigStore，保存成功后才提交完成状态，失败保持第二步并允许重试。启用仍检查相机权限、自检资格和白名单范围。

自检不关闭已经运行的保亮服务。已开启时完成按钮为「完成」，未开启时为「完成并开启」。SelfTestCoordinator 拥有自检采集资源，自检期间后台引擎避让；离页、后台、取消和 Activity 关闭释放资源。Home 后取消当轮并交还采集所有权，保留已通过步骤；返回自检页后重新取得租约，等待用户手动重试，不自动采集。会话和采集代次隔离旧结果、保存与 finally。预览销毁仅清预览，不因完成页移除预览而取消自检完成状态；离页由导航取消。controller 不重复取消由 coordinator 自己关闭的任务。
