# GazeKeep 文档索引

本文是仓库活动文档的路由页表，用于按任务选择需要加载的文档。它记录文档路径、适用场景、生命周期和最后复核日期；具体规则以根 `AGENTS.md`、沿目标路径逐层加载的目录 `AGENTS.md` 和相关架构为准，代码与测试证明实现现状，不能豁免安全承诺。

文档任务先加载仓库级 [docs-maintenance Skill](../.agents/skills/docs-maintenance/SKILL.md)，再根据下表读取命中的页面。没有命中时不要为了“完整”而加载整个 `docs` 目录。这里只维护当前有效内容，未完成事项见 [tasks/todo.md](../tasks/todo.md)。
