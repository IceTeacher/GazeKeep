# v1.1.8 迭代与发版规划

状态：待排期（草稿）。本文件承接原 `v1.1.7` 规划中为保证稳定性而顺延的场景适配与长时阅读增强功能（目标 `versionCode = 10`）；当前版本范围见 [v1.1.7 迭代规划](v1.1.7.md)，验收基线见 [任务清单与实测基线](todo.md)。

## 目标与发版定位

在 `v1.1.7` 完成保亮后端稳定性加固、SAF 本地配置迁移与连续注视稳态单帧快判后，`v1.1.8` 聚焦**「充电长时阅读不断流 + 平躺仰视兼容与多 ROM 后台引导」**，在不增加任何系统权限的前提下覆盖更多长时阅读与国产 ROM 场景：

- **充电阅读不断流**：支持「充电时不计单次保亮上限」可选开关，复用免权限充电状态探测，满足桌面支架充电看文档、菜谱等长时场景，拔电即刻恢复上限兜底。
- **平躺仰视阅读兼容与多 ROM 后台引导**：解决睡前平躺举手机仰视阅读（屏幕朝下 `Z < -0.8`）被 `FaceDown` 门控一刀切跳过的问题；同时将后台省电策略快捷跳转与防冻结说明从小米 HyperOS 扩展至 ColorOS、OriginOS、OneUI 与 Honor/Huawei。

### 不可变安全底线

本版全部改动必须继续满足 [Android 工程规则](../../apps/app/AGENTS.md#产品安全承诺) 与 [产品、术语与隐私](../product.md#隐私与安全红线)：

1. **Unknown 等价于 Away，默认熄屏**：充电豁免仅作用于单次保亮上限（`MaxHold`），一旦转头（`Away`）、看不清（`Unknown`）或链路中断，仍必须按系统原超时熄屏。
2. **拔电即刻恢复上限兜底**：充电期间不累计非充电保亮时长；拔电后的首次保亮必须重新计算并受 `maxHoldMinutes` 约束。
3. **关闭倒扣门控仍有兜底**：关闭倒扣桌面跳过后，真正倒扣在桌面时仍由接近传感器（`Pocket`）或相机全黑（`TooDark` → `TooDarkRepeatedly`）保证正常熄屏。
4. **零新增敏感权限**：多 ROM 后台策略跳转仅使用系统公开或常见设置页 Intent，失败时安全回退至应用详情页，严禁申请 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`。

## 详细设计方案

### 一、充电时豁免单次保亮上限（`unlimitedHoldWhileCharging`）

- **归属模块**：`core`（[Config.kt](../../apps/app/core/src/commonMain/kotlin/cn/rainafter/app/gazekeep/core/model/Config.kt)、[EngineEvent.kt](../../apps/app/core/src/commonMain/kotlin/cn/rainafter/app/gazekeep/core/engine/EngineEvent.kt)、[EngineSnapshot.kt](../../apps/app/core/src/commonMain/kotlin/cn/rainafter/app/gazekeep/core/engine/EngineSnapshot.kt)、[EngineReducer.kt](../../apps/app/core/src/commonMain/kotlin/cn/rainafter/app/gazekeep/core/engine/EngineReducer.kt)、`ConfigBackupCodec`）、`engine`（[ConfigStore.kt](../../apps/app/engine/src/main/kotlin/cn/rainafter/app/gazekeep/engine/config/ConfigStore.kt)、[DefaultEngineEffectRunner.kt](../../apps/app/engine/src/main/kotlin/cn/rainafter/app/gazekeep/engine/runtime/DefaultEngineEffectRunner.kt)）、`shared`（[SettingsScreen.kt](../../apps/app/shared/src/commonMain/kotlin/cn/rainafter/app/gazekeep/ui/screens/SettingsScreen.kt)）
- **设计方案**：
  1. **配置定义与备份扩展**：`GazeConfig` 新增 `unlimitedHoldWhileCharging: Boolean = false`（`ConfigStore` 键名 `unlimited_hold_while_charging`，默认关闭），并同步纳入 `ConfigBackupCodec` 导出/导入字段（向后兼容 `v1.1.7` 导出的配置，缺省保留 `false`）；在 `SettingsScreen` 的「单次最长保亮」下方（当 `maxHoldMinutes > 0` 时可用）提供「充电时不计保亮上限」开关。
  2. **引擎状态与拔电恢复语义（`EngineReducer`）**：
     - `EngineEvent.GateResult` 携带当轮 `isCharging: Boolean = false`（由 `DefaultEngineEffectRunner` 从 `GateInput.isCharging` 传入），`EngineContext` 维护当前已知的 `isCharging: Boolean = false`。
     - 当 `config.unlimitedHoldWhileCharging && context.isCharging` 成立时：若此前已存在 `holdStartUptime` 或 `forcedYieldPending`，清除 `holdStartUptime = null`、`forcedYieldPending = false` 并发出 `EngineEffect.CancelHoldLimit`；`extendFinished` 成功时不再记录 `holdStartUptime` 也不发出 `ScheduleHoldLimit`；`HoldLimitReached` 事件在该条件下直接忽略。
     - **拔电衔接边界**：充电期间不累计非充电保亮时长；当后续轮次 `GateResult` 探测到 `isCharging == false` 且 `config.maxHoldMinutes > 0` 时，自拔电后的首次 `ExtendResult.Done` 重新记录 `holdStartUptime = now` 并调度完整的 `ScheduleHoldLimit(start, start + maxHoldMs)`。

### 二、平躺仰视阅读兼容与多 ROM 后台省电策略引导

- **归属模块**：`core`（[Config.kt](../../apps/app/core/src/commonMain/kotlin/cn/rainafter/app/gazekeep/core/model/Config.kt)、[GatePolicy.kt](../../apps/app/core/src/commonMain/kotlin/cn/rainafter/app/gazekeep/core/policy/GatePolicy.kt)、`ConfigBackupCodec`）、`engine`（[ConfigStore.kt](../../apps/app/engine/src/main/kotlin/cn/rainafter/app/gazekeep/engine/config/ConfigStore.kt)）、`shared`（[SettingsScreen.kt](../../apps/app/shared/src/commonMain/kotlin/cn/rainafter/app/gazekeep/ui/screens/SettingsScreen.kt)、[PlatformActions.kt](../../apps/app/shared/src/commonMain/kotlin/cn/rainafter/app/gazekeep/ui/contract/PlatformActions.kt)）、`android`（[AndroidPlatformActions.kt](../../apps/app/android/src/main/kotlin/cn/rainafter/app/gazekeep/platform/AndroidPlatformActions.kt)）
- **设计方案**：
  1. **倒扣桌面跳过与平躺仰视阅读兼容**：
     - 在 `GazeConfig` 与 `ConfigStore` 新增 `faceDownGateEnabled: Boolean = true`（键名 `face_down_gate_enabled`，默认开启「手机倒扣时暂停」；副标题说明「屏幕朝下放桌面时跳过检测；若常平躺举手机仰视阅读可关闭」），同步纳入 `ConfigBackupCodec`（兼容旧备份缺省值 `true`）。
     - `GatePolicy.decide()` 仅在 `config.faceDownGateEnabled && input.faceDown == true` 时返回 `Skip(SkipReason.FaceDown)`。关闭倒扣门控后真正倒扣桌面时，仍由接近传感器（`Pocket`）或相机全黑（`TooDark` → `TooDarkRepeatedly`）保证正常熄屏。
  2. **多 ROM 后台省电策略引导扩充**：
     - 扩展 `AndroidPlatformActions` 的 `hasRomBackgroundPolicy()` 与 `openRomBackgroundPolicy()`，识别 Xiaomi/Redmi/POCO、OPPO/Realme/OnePlus、vivo/iQOO、Samsung/Honor/Huawei 并按候选顺序尝试跳转系统后台耗电管理页，失败时安全回退至 `openAppDetailsSettings()`，同步更新 [product.md](../product.md#安装启用与故障排查)。

## 阻断条件

- 充电豁免影响 `Away`/`Unknown` 正常熄屏，或拔电后不再受 `maxHoldMinutes` 约束；
- 关闭倒扣门控后，真正遮挡或暗黑环境未能正常熄屏；
- 多 ROM 后台引导在目标组件缺失时崩溃而非安全回退至应用详情页；
- APK Manifest 引入任何禁止权限。
